# Session: Logo and brand assets

## Request

"can you design a logo fo model picker?", then "can you make a few other designs
think outside the box you can exclude the current design and start from
scratch", then "i dont like any of these and no need to stick with that color",
then "dont like any of these", then "model picker circled is the one" and "once
done add the logos to all the right places in the repo and docs and create a PR
and merge it".

## Changes

Five rounds of exploration, each rendered and looked at rather than described:

1. Geometric marks built from diamonds, keeping the 🔶 the README already used.
   Three tiers with the middle one lit. Built in full, then rejected.
2. Eight more pictograms: faders, a gauge, a tuning fork, a throttle, mountains,
   a segmented control, a branching route, a bracket glyph. Rejected.
3. A change of category rather than shape: two wordmarks, a monogram, a mascot,
   an abstract block, a terminal glyph, each in its own palette. The highlight
   wordmark was the only one that worked. Still rejected.
4. Asked one question instead of guessing again. The answer was hand-drawn
   sticker: human, fun, open source, not corporate.
5. Four stickers. A pen circle round the word `picker` won.

The sticker renderer draws a cream die-cut edge under the artwork, shifts a
coral copy two units off-register, and can composite print grain through an SVG
filter. The pen circle is one bezier that overshoots its own start.

The old diamond assets were removed in the same branch. They were never on
`main`.

CodeRabbit caught a real bug in the first cut: every viewBox was the nominal
size of the drawing, but the die-cut edge is a wide stroke that sits outside it,
so the sticker outline was clipped on all four sides. `build.py` now measures
what it has to hold and a test fails if anything falls outside its own viewBox.

## Decisions

- The logo is the name. A pictogram kept reading as a settings button, and
  after eleven of them the register was the problem, not the drawing.
- One accent, coral. Amber was dropped with the diamonds.
- Shantell Sans, not a handwriting face: it has weight, bounce and informality
  axes, so the letters look drawn without looking like a note.
- The wordmark is outlined to paths. A logo that needs a font installed is not
  a logo.
- `advisor.py` was left alone. The 🔶 in the chat callout is plugin output with
  tests around it, and rebranding it is a separate change.
- No `icon` key in either manifest. `claude plugin validate` calls it unknown in
  both, so it would add a warning and nothing else.

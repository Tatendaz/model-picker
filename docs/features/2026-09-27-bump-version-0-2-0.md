# Feature: Version 0.2.0

**Branch:** chore/bump-version-0-2-0
**Date:** 2026-09-27

## Summary

Both plugin manifests move from 0.1.0 to 0.2.0, the first version that runs in
Claude Code as well as Codex.

## Motivation

Claude Code caches a plugin by version, so `/plugin update` needs a new number
to pick up the Claude Code support that landed in
[#4](https://github.com/Tatendaz/model-picker/pull/4). Codex shows the version
in `codex plugin list`, so the two manifests should not drift apart.

## What changed

- `plugins/codex-model-advisor/.codex-plugin/plugin.json`: 0.1.0 to 0.2.0.
- `plugins/claude-model-advisor/.claude-plugin/plugin.json`: 0.1.0 to 0.2.0.
- A test asserts that both manifests carry the same three-part version.

## Notes

Reinstall or update in each host to get the new version: `/plugin update
claude-model-advisor@model-picker` in Claude Code, and
`codex plugin update codex-model-advisor@model-picker` in Codex.

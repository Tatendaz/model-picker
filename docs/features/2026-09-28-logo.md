# Feature: Logo and brand assets

**Branch:** feat/logo
**Date:** 2026-09-28

## Summary

Model Picker has a logo. The mark is a pen circle drawn round the word `picker`:
one stroke that overshoots the start and crosses itself, the way anyone circles
the right answer on paper. The repository carries the logo, a square icon, PNG
exports, a brand board, and the script that redraws all of it.

## Motivation

The project used the emoji 🔶 as a stand-in in the README heading and in the
chat callout. An emoji cannot scale, cannot be recoloured, and says nothing
about what the plugin does. A drawn mark can: the plugin marks the model that
fits and leaves the switch to you, and a circle in pen is exactly that gesture.

## What changed

- `assets/brand/`: the logo (`lockup-*`), the icon (`icon-*`), PNG exports from
  512 down to 16 px, a print-size sticker, brand boards in both themes, and
  usage rules in `assets/brand/README.md`.
- `assets/brand/build.py`: redraws every SVG from one set of constants and
  outlines the wordmark from the Shantell Sans variable font, so no file is
  hand-edited and nothing needs the font installed to render. Each viewBox is
  measured from the artwork it has to hold, including the off-register copy and
  the die-cut edge, which is a wide stroke that sits outside the drawing.
- `README.md`: the emoji heading is now the logo, theme-aware through
  `<picture>`. A row in the documentation table points at the brand assets.
- `Makefile`: `make lint` now covers `assets/`.

Four variants ship for each of the logo and the icon. `-sticker` carries a cream
die-cut edge and works on any background; `-light` and `-dark` are flat and
transparent; `-mono` inherits `currentColor`. A `-sticker-grain` pair adds print
grain through an SVG filter, for renderers that support one.

## What did not change

No plugin behaviour, no hook, no manifest. The chat callout still opens with
`# 🔶 Model recommendation`, because that string is plugin output that the test
suite asserts on, and changing it belongs in its own change.

Neither host's manifest has an icon field. `claude plugin validate` reports
`icon` as unknown in both `plugin.json` and `marketplace.json`, so the manifests
were left alone rather than carrying a key that only produces a warning.

## Tests

`test_brand.py` covers the geometry and the assembly without fontTools or the
font, then parses every committed SVG: each has a viewBox and a label, the
wordmark is outlined rather than live text, the mono variants carry no fixed
colours, only the grain variants hold a filter, and nothing the file draws falls
outside its own viewBox. That last one is a real regression test — the first cut
of this change measured the viewBox from the artwork alone and clipped the
die-cut edge on all four sides.

## Notes

Colour is coral `#F2542D` on ink `#1C1B19` and paper `#FAF4E6`. Type is Shantell
Sans under the SIL Open Font License 1.1, outlined into the SVG files.

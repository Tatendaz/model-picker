# Feature: Model Picker initial release

Model Picker is a JEV-powered Codex plugin that recommends model and reasoning
settings as task scope grows. Users keep control of model selection. Bounded
request context, cooldowns, duplicate suppression, private local state and manual
rechecks support everyday use without a notice on every prompt.

The public package includes an MIT license, installation instructions, a repo
marketplace, tests on macOS/Linux and documentation of data sent to TypeSafe.
Automatic model switching is unavailable through the documented hook interface.
